# Contributing

## Branch workflow

1. Do not work directly on `main`.
2. Work on your assigned feature branch:
   - Sidney: `feature/fcfs`
   - Jeremy: `feature/sjf`
   - Sarai: `feature/priority`
   - Jonathan: `feature/round-robin`
3. Pull the latest `main` before starting work.
4. Commit changes with clear, descriptive messages.
5. Push your feature branch to GitHub.
6. Open a pull request from your feature branch into `main`.
7. Ask another team member to review the pull request before merging.

Keep pull requests focused and include relevant test results in the description.
